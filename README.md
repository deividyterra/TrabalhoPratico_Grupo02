# TrabalhoPratico_Grupo02
Trabalho prático da disciplina de Práticas de Programação Orientada a Objetos, do curso de Ciência da Computação da Universidade Federal de Lavras (UFLA), período letivo 2026.2. Jogo de aventura em Java baseado no World of Zuul, em que um caçador de tesouro explora uma casa mal assombrada por comandos textuais e interface gráfica.
